# Candle Shop Learning Project

This is an E-commerce web application for a candle store that I'm building as a personal project to learn and practice ASP.NET Core 10 and professional software development principles.

## Project Goal
My main objective with this project is to gain hands-on experience with:
- Mastering **ASP.NET Core 10** concepts.
- Implementing **Clean Architecture**.
- Working with **Entity Framework Core** and **SQL Server**.
- Understanding project structure and modular development.

## Tech Stack
- **Framework:** ASP.NET Core 10
- **ORM:** Entity Framework Core
- **Database:** SQL Server

## Status
This project is currently under development. I'm actively adding new features (like user authentication, candle management, etc.) as I progress with my learning path.
